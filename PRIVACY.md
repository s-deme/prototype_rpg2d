# Privacy Policy

Alice & The Broken Crown does not send gameplay, identity, analytics, or crash data to a network service.

The game stores settings and up to three local save slots using Unity `PlayerPrefs` on the player's device. These values contain game progress, dialogue-log entries, settings, key bindings, and play statistics only. Each slot can be deleted from the in-game save-data screen; deleting the application data removes all records. The game does not provide cloud synchronization by default.

If this project is later distributed through a platform with cloud saves, analytics, or crash reporting, this policy must be updated before release.
